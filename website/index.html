Tout ce dont tu as besoin

📨

DM de masse

Envoie un message privé à tous les membres de ton serveur en une seule commande.

🎭

Ciblage par rôle

Ajoute le paramètre role pour n'envoyer le DM qu'aux membres d'un rôle précis.

🔒

Admin uniquement

La commande est protégée : seuls les administrateurs du serveur peuvent l'utiliser.

📊

Rapport d'envoi

À la fin, le bot affiche le nombre de DMs envoyés et d'échecs (membres avec DMs fermés).

⚡

Rate-limit respecté

500 ms d'intervalle entre chaque DM — aucun risque de ban par les API Discord.

🌐

Multi-serveurs

Un seul bot, autant de serveurs que tu veux. Les commandes sont enregistrées globalement.

Comment ça marche ?

1

Invite le bot sur ton serveur

Clique sur le bouton "Inviter le bot" et sélectionne ton serveur. Les permissions Administrateur sont requises pour que le bot puisse lire les membres et envoyer des DMs.

2

Utilise la commande /dmall

Tape /dmall message:Ton message dans n'importe quel salon. Ajoute role:@UnRôle pour cibler un rôle spécifique.

3

Reçois le rapport

Le bot t'envoie un résumé en temps réel : nombre de DMs envoyés avec succès, et nombre d'échecs (membres avec DMs désactivés).

Prêt à l'utiliser ?

Gratuit, sans inscription. Invite le bot en un clic.
